## Sobre o Projeto

**GitSearch** permite pesquisar qualquer usuário do GitHub e visualizar informações detalhadas do perfil, como repositórios, seguidores e seguindo, com uma interface limpa e intuitiva.

---

## Tecnologias

- **Swift** — linguagem principal do desenvolvimento
- **UIKit** — componentes nativos iOS
- **GitHub REST API** — dados de perfis e repositórios
- **URLSession** — requisições HTTP
- **Xcode** — ambiente de desenvolvimento

---

## Funcionalidades

- Busca de usuários pelo nome de usuário do GitHub
- Exibição de avatar, nome, bio e estatísticas do perfil
- Listagem de repositórios públicos
- Navegação entre perfis

---

## Como Executar

1. Clone este repositório
2. Abra o arquivo `SearchGit.xcodeproj` no **Xcode**
3. Selecione um simulador iOS ou dispositivo físico
4. Pressione **Cmd + R** para rodar
